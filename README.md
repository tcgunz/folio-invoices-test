# Folio — Invoices trial

A separate trial copy of [Folio](https://github.com/tcgunz/folio) with a new **Invoices** section:

- Create invoices with your business details, client, line items and tax
- Save as PDF and send with your phone's share menu (Gmail, Outlook, Messages…)
- Track paid, unpaid and overdue invoices; export a CSV for your accountant
- Optional: hide Invoices from the File menu

This copy keeps its own saved files and settings, separate from the main Folio app.
